# 세포 관리 시뮬레이션 v0.1

기획서: 「세포 관리 시뮬레이션 — 기획서 v0.1」(Claude Docs). 핵심 루프 검증용 프로토타입.

## 실행
```
python3 -m http.server -d cell-sim 8000   # 저장소 루트에서
```
브라우저에서 http://localhost:8000. `config.json`을 fetch하므로 file://로는 열리지 않는다.

## 구조
- `config.json` — 밸런스 수치 전부 (기획서: JSON 분리)
- `src/sim.js` — 시뮬레이션 코어. DOM 무의존, 고정 10 Hz 틱, 정수 카운터, 시드 RNG
- `src/main.js` — Canvas 렌더링·UI (흑백 전용)
- `test/` — `npm test` (node --test)
- `tools/balance.mjs` — 스크립트 봇으로 8개 시드 플레이, 승패·소요 시간 출력

## 구현 시 확정한 사항 (기획서 미기재·미결정 항목)
| 항목 | 결정 |
|---|---|
| 발효 전환 | 자동. O₂ < 1 또는 피루브산 ≥ 상한 50%일 때 |
| 소기관 거리 | v0.1 미적용. 배치는 시각적 위치만 |
| 원핵 막 면적 | 막 슬롯 = 3 × 크기². 부피 유지비 = 0.5 × 크기³. 최대 크기 3 |
| 공생 이벤트 | 최대 크기에서 단백질 15 + ATP 60 지불, 20초간 항상성 임계 없으면 성공 |
| 수송체 기질 | 수송체마다 포도당/아미노산 모드 전환 |
| ATP 포화 | ATP 상한 근접 시 해당과정·호흡 정지 (피드백 저해) |
| 막 마모 상쇄 | 기본 막 합성(단백질 1 → 막 +2, 0.15/s). 골지체는 추가 수리 |
| 폐기물 임계 | 소기관 효율 50%, 소기관 내구도 2/s 감소, 0이면 소실. 핵 소실 시 패배 |
| 바이러스 | 막 50% 미만에서 침투 → 리보솜 1개 탈취(투입물 소비, 3회마다 복제). 리소좀이 우선 분해 |
| 원핵 단계 위협 | 저산소·영양 결핍만 발생 |
| 승리 | 진핵 단계에서 단백질 50 보유 시 세포분열 실행 |
