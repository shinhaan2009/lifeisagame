# 세포 관리 시뮬레이션 v0.2 (팩토리형)

기획서: 「세포 관리 시뮬레이션 — 기획서 v0.1」(Claude Docs). 세포 = 공장, 대사 경로 = 생산 라인을 타일 그리드 물류로 구현한 프로토타입.

## 실행
```
python3 -m http.server -d cell-sim 8000   # 저장소 루트에서
```
http://localhost:8000. `config.json`을 fetch하므로 file://로는 열리지 않는다. 테스트: `cd cell-sim && npm test`.

## 조작
| 입력 | 동작 |
|---|---|
| 1–8 | 건물 선택 (5는 원핵: 막 호흡 복합체, 진핵: 미토콘드리아) |
| 클릭 | 배치 / 선택 |
| 드래그 (미세소관) | 이동 방향을 따라 연속 설치 |
| R | 미세소관 방향 회전 (도구 없이 호버 시 해당 타일 회전) |
| 우클릭·우클릭 드래그, X | 제거 (전액 환불) |
| Space / Esc | 일시정지 / 취소 |

## 체계
| 팩토리 장르 요소 | 세포 대응 |
|---|---|
| 채굴기 | 막 수송체 (막 타일 전용, ATP 1 → 포도당/아미노산) |
| 컨베이어 | 미세소관. 타일당 최대 5개, 2 타일/s. 앞이 막히면 정체 |
| 조립기 | 해당 효소 군집, 리보솜, 미토콘드리아(2×2), 리소좀, 골지체(2×2) |
| 전력망 | ATP 전역 공유. 0이면 모든 기계 25% 속도 |
| 본진 | 핵(원핵: 핵양체). 단백질 납품처이자 건설 자원 창고 |
| 오염 | 세포질 폐기물 농도. 막힌 출구·발효·막 호흡이 세포질로 배출 |

- 기계는 인접 미세소관 중 자기를 향하지 않는 것으로 출력을 순환 배출한다.
- 미세소관이 기계를 향하면 그 기계가 받는 아이템만 들어간다.
- 해당 효소 군집은 출구가 막히면 자동 발효(피루브산 대신 세포질 폐기물 2).
- 원핵 성장 시 막 건물은 같은 방위각의 새 막으로 이동한다. 미세소관은 재연결해야 한다.

## 기획서 대비 변경
| 항목 | 변경 |
|---|---|
| 해당과정 | 세포 기본 기능 → 건물(해당 효소 군집). 물류 경로가 필요해서 |
| 배출 펌프 | 추가. 폐기물을 미세소관으로 막까지 보내 배출 |
| 소기관 거리 (미결정) | 확정: 거리 있음. 물류 길이와 정체가 곧 거리 비용 |
| 발효 전환 (미결정) | 자동. 해당 군집의 출구 정체가 트리거 |
| 단백질 | 건설 자원은 핵에 납품된 단백질만 사용 |
