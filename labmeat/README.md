# 배양육 회사 경영 시뮬레이션 v0.1 (Unity 프로토타입)

기획서: 「배양육 회사 경영 시뮬레이션 — 기획서 v0.1」(Claude Docs). MVP 범위를 그레이박스로 구현했다.

## 실행
1. Unity Hub → Add project from disk → 이 `labmeat/` 폴더. Unity 6 LTS(6000.0) 또는 2022.3 LTS, 내장 렌더 파이프라인.
   처음 열 때 `ProjectSettings/`가 자동 생성된다.
2. 빈 씬에서 Play. 씬·프리팹이 없어도 `GameManager`가 자동 생성되어 맵·플레이어·UI를 코드로 만든다.

## 조작
| 키 | 동작 |
|---|---|
| WASD · 마우스 · Shift | 이동 · 시점 · 달리기 |
| E | 상호작용 (리액터, 작업대, 냉장고, AI 컴퓨터, 침대, 택배함, 지인 집, 택시) |
| Tab | 휴대 단말 (메시지·주문·리액터 요약·뉴스) |
| F1 / F2 / F3 · P | 배속 1× / 2× / 4× · 일시정지 |
| Esc | 패널 닫기 / 메뉴 |

## 구조
```
Assets/Scripts/Sim/     순수 C# 시뮬레이션 (UnityEngine 참조 없음). 고정 틱 = 게임 1분
  Game.cs               시간·현금·하루 정산
  Game.Production.cs    리액터 배치·오염·수확, 작업대, 냉장고, 재료 주문·택배
  Game.Research.cs      연구 5축, 확률 결과, AI 연구 보조
  Game.Sales.cs         지인 주문·배달·입소문, 레스토랑 계약, 수출
  Game.Company.cs       투자 라운드·Phase 관문, 국가 승인, 여론, 사건, 뉴스
  Game.Hiring.cs        숨은 능력치, 면접, 검증, 연봉 협상, 직원 근무
Assets/Scripts/Game/    Unity 층: 그레이박스 맵 생성, 1인칭 이동, IMGUI 패널
Assets/Resources/balance.json   밸런스 수치 전부
Tests~/SimTests/        코어 테스트 + 스크립트 봇 (Unity가 무시하는 ~ 폴더)
Tests~/UnityCompile/    UnityEngine 참조 어셈블리로 게임 스크립트 컴파일 검사
```

## 검증 (Unity 없이)
```
dotnet run --project "Tests~/SimTests"              # 테스트
dotnet run --project "Tests~/SimTests" -- bot -v    # 봇 6시드 120일 플레이
dotnet build "Tests~/UnityCompile"                  # 게임 스크립트 컴파일 검사
```

## 하루 흐름 (Phase 1)
아침에 리액터 점검·배지 교체 → 낮에 수확·작업대 가공·냉장고에서 꺼내 지인 집 배달, AI 컴퓨터로 재료 주문(다음 날 9시 택배함) → 저녁에 연구 예산 배분 → 침대에서 잠들면 정산. 새벽 2시까지 안 자면 기절한다.

## 기획서 해석·구현 결정
| 항목 | 결정 |
|---|---|
| 시간 | 게임 1분 = 실제 1초(1×). 07:00 기상, 18:00부터 취침 가능, 02:00 기절 |
| 연구 결과 | 축별 일일 예산이 누적 점수가 되고, 밤마다 성공 확률 1−e^(−점수/난이도)로 판정. 성공 중 22%는 돌파(+1.5레벨), 나머지는 부분 성공(+0.5). 실패 시 점수 60% 유지. 축마다 판마다 다른 숨은 난이도가 있다 |
| AI 연구 보조 | 숨은 난이도를 연산 장비 정확도만큼만 알고 추천. 틀릴 수 있다 |
| 오염 | 시간당 확률(배지 신선도·무균화 연구·직원 꼼꼼함 반영). 숨겨져 있고, 점검 수치(pH 하락·탁함)로 점점 드러난다. 모르고 팔면 사고 이벤트 |
| 너겟·소시지 | 5개 연구 축에 없는 "지방세포 배양 연구"를 세포주 Lv2(지방세포 분화)로 대체 |
| 시리즈 A 조건 | MVP의 "국가 1곳 = Phase 3 진입 조건용"에 맞춰 첫 국가 승인을 시리즈 A 조건에 포함 |
| 상업 규모 리액터·통짜 컷 | 정의만 두고 잠금 (v0.2) |
| 직원 | Phase 2(공유 실험실)부터. 배양·가공·연구 역할로 자동 근무 |
| 차고 배치 | 리액터 3자리 고정 배치. 플레이어가 직접 옮기는 기능은 미구현 |
| 원가 수치 | 기획서대로 밸런스 단계로 미룸. 현재 값은 봇 기준 엔젤 13–21일, 시리즈 A 36–45일 |
